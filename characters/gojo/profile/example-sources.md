# 五条悟回复示例出处

修订日期：2026-10-05。当前 role.json 的 examples 仅保留3条有公开引文可核对的短句；此前25条编者原创示例已从运行设定撤下，备份仅供历史回溯。

## 文本身份

每条 assistant 是日文原句的简短中文直译。日文原句、作品位置与核对链接只保存在本文；运行字段 situation 仅保留理解对白所需的简短场景。中文措辞不是某个官方中文译本或字幕组的逐字引用。未获取指定中文版本，因此不混用不同字幕或将自行翻译写成中文原文。第三条仅节录原台词的第一分句，未补写其后半句。

user 字段是编者根据原作情境整理的示范提问，不是原作另一位人物的原话。情境说明、来源标注与角色行为分析同样是编者说明，不计作作品台词。

## 使用方式与扩充

宿主 ContextBuilder 会把每条 examples 转成两个模型消息：带【角色对白示例】标记的 user（情境及提问），以及 assistant（JSON 对象，text 原样使用上述译文，speaker 使用角色 ID，expression 使用默认表情，action 为 null）。顺序为系统设定、全部示例问答、会话资料及真实对话。模型客户端将这些消息分别映射为 HumanMessage 和 AIMessage，交给当前 API 适配器。

本文不会进入模型 messages。示例参与上下文预算，但不写入聊天记录、长期记忆或真实历史消息计数。短句供模型理解原场景中的从容、自信与重要关系表达，不要求在无关问题上机械复读，尤其不能对真实困难许诺虚构战力。

原项目曾通过上下文探针和本机模拟服务核对待发送消息，以及通用 Chat Completions、DeepSeek 和 Responses 三种适配器的实际请求。该探针和历史报告未纳入当前仓库；问题及回应为合成测试资料，不使用真实密钥，也不评估真实模型的扮演质量。当前请求装配实现见 `src/main/chat/ContextBuilder.ts`。

作品有版权，本次只保留少量短引用，不从网络批量拼成长篇台词集。若需扩充整套原文示例，请提供准备采用的台词文本或译本摘录；可在用户提供的文本范围内尽量保持原句，整理位置、场景与出处。

本次只改模型回复示例。interaction/dialogues.json 的固定点击、问候与按钮台词仍为本项目原创，未标成原作引用。后续如果也要改那部分，应单独提供对应原文，避免把原台词硬挪到不相干场景。
