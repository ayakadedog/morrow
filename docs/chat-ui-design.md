# 聊天工作区改版

日期：2026-10-11。版本：0.4.1-chat-workspace。

## 参考与取舍

- [Ant Design X](https://x.ant.design/components/overview/)：参考会话导航、消息、输入和推理展示的职责划分。[Sender](https://x.ant.design/components/sender/) 提供了附件、停止、自动高度等聊天输入交互的参考。
- [Vercel Chatbot](https://vercel.com/templates/next.js/vercel-x-xai-chatbot)：参考简洁的聊天主区与响应式组织。
- [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/base/sidebar)：参考固定头尾、独立滚动的导航区。

保留现有 React、Ant Design 图标和 Electron IPC，不引入新的聊天 SDK或 UI 框架。采用暖白、灰绿与低饱和薄荷色，适应暮伴的陪伴定位。桌宠、气泡和独立数据管理后台不使用聊天工作区的样式。

## 已实现

- 顶部应用导航；聊天页移除占用高度的大角色卡与日常设置页脚。
- 左侧角色信息、新对话、对话/记忆/模型导航、历史会话和后台入口。
- 搜索调用现有 SQLite 会话查询，不限于已加载的 50 个会话；搜索结果目前单页最多 50 条，可到独立会话管理查看更多。
- 会话标题、改名入口和真实配置状态；“模型已配置”不声称已验证云端在线。
- 聊天区随窗口伸缩，消息按日期分组，展示角色署名与时间。
- 消息工具在悬停或键盘聚焦时显示；窄窗口常显。保留记忆确认、编辑重发、再生成与撤回，补充复制反馈。
- 角色欢迎页与三条话题建议；建议只填写输入框，不自动调用模型。
- 输入框自动增高，固定在聊天主区底部；保留中文输入法、Enter 发送、Shift+Enter 换行、图片和停止。
- 阅读旧消息时不强制跳到底部，提供“回到最新消息”。
- 上下文、记忆快照、摘要、请求诊断和清理入口折叠为“会话详情与整理”。
- 记忆与模型页面独立滚动。纠正旧界面中自动记忆“一律1.5秒”的错误说明。
- 650px 以下切为紧凑导航与会话选择，仍可打开完整会话列表。

## 文件与运行

- `src/renderer/src/ChatPanel.tsx`：界面组织、会话搜索、自动高度与复制。
- `src/renderer/src/chat-workspace.css`：局部样式与响应式断点。
- `src/renderer/src/main.tsx`：聊天工作区外壳，其他设置保留。
- `src/main/index.ts`：窗口默认 1040 × 820，并限制在工作区内；仍允许缩至 440px。
- `scripts/verify-chat.mjs`：调整导航路径并验收会话搜索、布局、快捷键与原有聊天功能。
- `scripts/start-chat.cmd`：启动新版包，继续使用 `data/local`。

关闭正在使用的旧版后，再通过新启动脚本打开。测试使用独立 `data/tests/chat`、合成对话和本地模拟模型，不读取真实聊天、密钥，不消耗真实模型额度。

实际窗口截图保存于 `artifacts/screenshots/聊天新版-*` 和 `聊天面板-M2-*`；完整聊天验收报告位于 `artifacts/reports/M2-chat-*-check.json`。

## 验证结果

- 角色包校验、TypeScript、生产构建及 Windows 运行包生成通过。
- 16 个单元测试文件，238 项通过。
- 源码实际窗口 23 项检查通过；包内实际窗口 22 项通过（源码额外检查一组专用测试角色切换）。
- 覆盖流式/非流式、思考与回答、停止、编辑重发、重新生成、撤回、重启、超过 50 个会话的名称搜索、原文分页、图片选择与大图预览。
- 宽屏及 440px 窄窗口无横向溢出，输入区保持可见；最终缩略图文件名上下排版另经实际截图复查。
- 测试使用合成数据和本地模拟模型，不作为真实模型语义效果的评测。

## 当前边界

消息仍按原有纯文本协议显示，没有新增 Markdown 渲染；会话搜索是名称的模糊搜索。记忆算法、模型连接与存储结构沿用现有实现。本次没有导入 Ant Design X 的模型传输层。
